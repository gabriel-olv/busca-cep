# Consulta CEP

Projeto desenvolvido com base no conteúdo do curso **Carreira Back-End Java**, da [Alura](https://www.alura.com.br/).

A aplicação realiza consultas de CEPs por meio da API pública [ViaCEP](https://viacep.com.br/), permitindo informar um CEP, o número e, opcionalmente um complemento, e obter o seu endereço completo.

## Tecnologias utilizadas

- **Java 25** — Linguagem de programação.
- **Maven** — Gerenciamento de dependências e build.
- **Gson** — Serialização e desserialização de JSON.
- **ViaCEP** — API pública para consulta de CEPs.

## Funcionalidades

- Consulta de endereços por CEP.
- Integração com a API ViaCEP.
- Consumo e interpretação de respostas JSON.
- Conversão dos dados recebidos para objeto Java.

## Objetivo do projeto

Praticar conceitos fundamentais de desenvolvimento back-end com Java, incluindo:

- Consumo de APIs REST.
- Requisições HTTP.
- Manipulação de JSON com Gson.
- Organização e estruturação de código Java.
- Gerenciamento de dependências com Maven.
